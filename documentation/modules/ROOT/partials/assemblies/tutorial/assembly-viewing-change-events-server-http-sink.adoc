= Viewing change events

After deploying the {prodname} MySQL connector,
it starts monitoring the `inventory` database for data change events.

When you watched {prodname} server and the connector start up,
you saw that events were being streamed to the HTTP Sink at `http://127.0.0.1:8081`

As events are received, they are output to the standard output of the container the HTTP Sink is running in, which can be viewed using `docker logs httpsink`.
In this topic, you will see different types of change events to see how the connector captured them:

* xref:viewing-create-event-http-sink[Viewing a _create_ event]
* xref:updating-database-viewing-update-event-http-sink[Updating the database and viewing the _update_ event]
* xref:deleting-record-database-viewing-delete-event-http-sink[Deleting a record in the database and viewing the _delete_ event]
* xref:restarting-{prodname}-server-http-sink[Restarting {prodname} server and changing the database]

= Updating the database and viewing the _update_ event

By updating a record in the database and observing the change event that the {prodname} MySQL connector captures, you can learn how to identify what changed in a commit and compare events to determine their sequence.

.Procedure

. In the terminal that is running the MySQL command line client, run the following statement:
+
--
[source,sql,options="nowrap"]
----
mysql> UPDATE customers SET first_name = 'Johnathan', email = 'johnathantutorial@example.com' WHERE last_name = 'Tutorial';
Query OK, 1 row affected (0.00 sec)
Rows matched: 1  Changed: 1  Warnings: 0
----
--

. View the updated `customers` table:
+
--
[source,sql,options="nowrap"]
----
mysql> SELECT * FROM customers;
+------+------------+-----------+-------------------------------+
| id   | first_name | last_name | email                         |
+------+------------+-----------+-------------------------------+
| 1001 | Sally      | Thomas    | sally.thomas@acme.com         |
| 1002 | George     | Bailey    | gbailey@foobar.com            |
| 1003 | Edward     | Walker    | ed@walker.com                 |
| 1004 | Anne       | Kretchmar | annek@noanswer.org            |
| 1006 | Johnathan  | Tutorial  | johnathantutorial@example.com |
+------+------------+-----------+-------------------------------+
5 rows in set (0.00 sec)
----
--
